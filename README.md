# ScientificComputingProject1

Project 1 for Scientific Computing. A basic Python program to convert a file from one sample rate to another. 
To run this program:
1. Compile and run resampling.py
2. Input the file path for your .wav file
3. Input the file path and name for your desired resampled .wav file
4. Input the sample rate of your .wav file as an integer (no "," or "-" separating place values)
5. Input the desired sample rate of your resampled .wav file as an integer (no "," or "-" separating place values)
